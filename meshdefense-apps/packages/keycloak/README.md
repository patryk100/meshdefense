# Keycloak Package (Air-Gapped SSO & DoD PKI)

Keycloak serves as the centralized identity provider for Big Bang services (GitLab, SonarQube, Grafana, Harbor).
- **Authentication**: Supports DoD CAC / Smart Card PKI authentication and internal LDAP/Active Directory federation.
- **Air-Gap Hardening**: Built from Red Hat Keycloak Iron Bank container image.
