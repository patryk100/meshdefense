# NeuVector Package (Air-Gapped Container Security)

NeuVector provides real-time container network segmentation, runtime behavioral monitoring, and CIS benchmark scanning in the IL6 enclave.
- **Air-Gap Mode**: Automated internet CVE updater is disabled.
- **Offline DB Sync**: CVE feeds are packaged on low-side and injected into NeuVector controllers via `meshdefense-apps/scripts/update-vuln-db.sh`.
